# Problem 4: Is the Queue in Order?

SRM SEM-3 · CodInClub — Category C · Sorting Algorithms (Java).

Single pass from index 1: returns the index of the first token smaller
than the one before it (equal neighbours are allowed), or `-1` when the
whole queue is in order. An empty queue or one student is always in order.

## Run

```sh
cd src
javac QueueInOrder.java
java QueueInOrder
```

Tests the two sample inputs plus one extra input.
